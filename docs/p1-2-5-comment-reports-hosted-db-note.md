# P1-2.5 호스팅 DB 적용 메모

호스팅 DB에는 P1-2.5 작업 중 생성된 초기 관리자 RPC 시그니처가 일부 남아 있어 최종 계약과 충돌했다.

처리:

- 기존 초기 시그니처를 제거했다.
- 저장소의 최종 관리자 RPC 계약과 동일한 함수 정의를 재적용했다.
- 최종 함수 시그니처와 SECURITY DEFINER 상태를 재검증했다.
- 신고·결정 테이블에 anon/authenticated 직접 권한이 없음을 확인했다.

이 메모는 호스팅 환경의 작업 이력을 기록하기 위한 것이며, 신규 환경은 `20260723010000`~`20260723012000` 마이그레이션을 순서대로 적용하면 된다.

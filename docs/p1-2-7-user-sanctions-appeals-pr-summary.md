# P1-2.7 PR 요약

## 범위

- 사용자 경고, 댓글 제한, 신고 제한, 계정 활동 제한
- Append-only 제재·이벤트 감사 원장
- 현재 효력 projection
- 본인 제재 조회와 제재당 단일 이의제기
- 관리자 제재 생성·조기 해제·이의제기 수용·기각
- 댓글, 신고, 좋아요, 북마크 mutation capability enforcement
- 제재·이의제기 알림
- 사용자 및 관리자 운영 화면
- 기간 만료 service-role RPC

## 검토 보완

- 만료 후 이의제기 수용을 보존하도록 expiry와 overturn 이벤트 제약 분리
- 관리자 계정 제재 금지
- 동일 종류 활성 제재의 동시 중복 생성 차단
- 감사 원장과 현재 상태 projection 분리
- 계정 제한 중에도 제재 조회와 이의제기 허용

## 병합 정책

Exact-head CI와 Hosted 검증 완료 후에도 사용자 명시 승인 전에는 병합하지 않는다.
